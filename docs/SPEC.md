# Vessel — дизайн (итог grill-сессии 2026-10-11)

**Суть:** планировщик, где каждый день — сосуд объёмом 24ч, а сетка дней жизни — дашборд всех сосудов.
Только план, без отслеживания реального времени. Цель — наглядно показать, как мало на самом деле свободного времени.

## Сосуд дня
- 2D: квадрат без верхней стенки. Внутри — «падающий песок» в духе [thisissand](https://thisissand.com/) / [sandspiel](https://sandspiel.club/): сетка 240×240 песчинок, 40 песчинок = 1 минута, 10 рядов = 1 час. Шкала 0–24ч на стенке.
- Каждая песчинка занимает ровно одну клетку — объём честный без «утрамбовки». Горки и волнистые пласты не выравниваются (решение 2026-10-12: «не обязательно выравнивать»).
- Рутина — пласты на дне. Задачи досыпаются сверху в порядке принятия; выросшая задача досыпается сверху, уменьшившаяся — теряет верхние песчинки, и всё сверху оседает.
- Добавление: черновик → призрачный контур → «Принять» → песок сыплется струёй с «гуляющей» плотностью — отсюда волнистые слои.
- Выполненные пласты яркие, невыполненные блёклые, рутина приглушённая. У песчинок шум яркости — зернистость.
- Горка выше края, но всё влезает — песок оседает в ямки. Не влезает — ямки засыпаются, лишнее течёт к стенкам и водопадом ссыпается на пол (ровно столько, сколько не влезло).
- **Новая задача не влезает** → контур краснеет, «Принять» заблокирована. Варианты: перенести на ближайший день, где влезет; сократить; убрать/перенести низкоприоритетное. «Добавить всё равно» нет.
- **Выросло существующее** (правка, рутина, повтор) → лишние частицы вываливаются через край на пол, день красный. Клик по кучке → те же варианты.

## Задача
Название, категория (готовый набор), длительность *или* интервал (через полночь — делится между днями), приоритет (3 уровня), подзадачи-чеклист, повтор (как в Google Calendar, правка «только эту / эту и следующие»), дома/вне дома (дефолт от категории).
- «Вне дома» → вопрос про дорогу (туда+обратно) → отдельный пласт «Дорога», привязанный к задаче.
- Невидимое время: сборы перед выходом и восстановление (душ после спорта) — подсказки по категории, отдельные пласты. Буфер между задачами — глобальная опция, по умолчанию выключен.

## Обороты — параллельные дела (2026-10-12)
«Бег + подкаст», «дорога + аудиокнига», «еда + сериал». Оборот — второе дело внутри пласта первого: **места в сосуде не занимает**, время «прожито дважды».
- Оборот — лёгкая задача: название, категория, своя галочка, необязательная цель. Дата и повтор — от основного дела.
- Длительность ≤ основного дела (по умолчанию равна). Один оборот на пласт.
- Есть у задач, у их дороги/сборов/восстановления и у пунктов рутины (в шаблоне — для всех дней; в дне — только на этот день).
- В песке: часть песчинок пласта — крапинки цвета оборота (до половины, пропорционально длине). В тултипе «Бег ⇄ Подкаст 40м».
- **Слияние:** «Совместить с…» делает задачу оборотом другого пласта — её песок впитывается, место освобождается (длинная задача — остаток остаётся отдельной). «Разделить» — обратно.
- Засчитывается в категорию и цель оборота; в «Итогах» — «Прожито дважды» и сегмент «параллельно». Если резерв цели в этот день уже закрыт оборотом — карточка резерва предлагает убрать его.
- Карточки задач переворачиваются (⇄): лицевая — дело, оборотная — что параллельно. Это структура для будущего дизайна.

## Работа (2026-10-12)
Работа — отдельный класс, не рутина. Три яруса дня: **тело** (рутина) → **работа** → **своё**.
- **Основная работа** — контейнер по графику (Пн–Пт 8ч) со своей дорогой (невидимое время работы). Рабочие задачи **заполняют блок изнутри**; если их больше блока — **переработка**: блок растёт и съедает «своё» (видно в шкале, сводке дня, «Итогах»).
- **Фриланс** — без графика; его задачи и **проекты** (заказ = цель с источником работы + оценка часов + дедлайн + «по N мин в дни недели») — ярус поверх, в «своё» время. У проекта — темп «нужно ≈X в день».
- **Выходной** — кнопка у блока на день; **отпуска/больничные** — диапазоны дат в настройках работы. В эти дни блок и дорога исчезают; рабочие задачи в такой день — переработка.
- Обороты: во время работы и в дороге на работу (на день или по шаблону работы).
- Миграция: «Работа» и «Дорога на работу» из старой рутины переехали в основную работу (с переопределениями и оборотами), задачи категории «Работа» — внутрь блока (раньше они ложились поверх и дублировали время).
- Для сеток «основание» дня = рутина + блок работы + дорога; «запланировано» = своё, фриланс и переработка.
- Сменный график и клиенты отдельным списком — потом.

## Рутина
Шаблон пунктов (длительность + дни недели), переопределение на конкретный день. В списке — свёрнутая группа без галочек.

## Сетка жизни (этап 2)
3 зума: Жизнь (строка = календарный год, у каждого месяца блок на 31 клетку — месяцы выровнены; на телефоне год в две строки по 6 месяцев; «прожито / осталось N дней / ≈ недель») → Год (календарь, клетки = мини-сосуды) → День.
Клик в «Жизни» открывает год с выбранным днём (клетки по 1–3 px — точно попасть нельзя), клик в «Годе» — день.
Прошлое серое, сегодня зелёное (с рамкой — видно даже на крошечной сетке), будущее неактивное. В «Жизни» оттенок — только запланированное (иначе рутина сливает все дни), красный — переполнено. В «Годе» рутина — бледное основание мини-сосуда, запланированное — ярко сверху.
Недельный сосуд — только просмотр, тот же песок на шкале 168ч; пласты по категориям: внизу рутина, выше сделанное, сверху запланированное. Рядом — дни недели со свободным временем и «куда уходит неделя».

## Цели (этап 3)
Создаются формой (название, срок с быстрыми вариантами месяц/3 месяца/полгода/год, цвет, категория) — из панели целей в «Жизни» и «Годе». Протягивание по сетке — позже, в мобильной версии.
На «Жизни» — подложка цвета цели под днями срока, на «Годе» — полоски под клетками (до 3 целей).
Опционально «N мин в эти дни недели» → серия-резерв, пласт в каждом дне срока **начиная с сегодня** (не задним числом). Цвет пласта — по категории цели, в тултипе «(цель)».
Задачу можно привязать к цели. Цель копит часы «сделано из запланировано» и серию дней с прогрессом по чек-инам.
Удаление цели заканчивает резерв с сегодняшнего дня; прошлые задачи остаются без привязки.

## Чек-ин (этап 3)
При первом открытии за день — про вчера: оценка 1–5 (обязательна для сохранения), прогресс по каждой активной цели (продвинулся / чуть-чуть / нет), заметка.
Пропущенные дни не опрашиваем по отдельности: невыполненное за весь пропущенный отрезок (до 14 дней) — одним списком с переносом на сегодня. Повторяющиеся задачи по умолчанию не переносятся.
«Пропустить» не спрашивает снова в тот же день. Выключается в настройках.
На «Годе» — цветная точка оценки, на «Жизни» прошлый день подкрашивается цветом оценки.

## Итоги (этап 3)
Отдельная вкладка, неделя/месяц. Плитки: свободно за период, % выполненных задач, средняя оценка, переполненные дни.
Дни по загрузке — по свободному времени: свободный > 4ч, нормальный 1–4ч, под завязку < 1ч, переполнен — не влезло.
«Куда ушло время» — по категориям: сделано / запланировано (+ рутина по флажку). Категория подписана текстом, полосы — одним цветом по смыслу (палитра категорий не годится как палитра графика: не проходит проверку на различимость).
Цели за период: часы и отметки чек-инов.

## Онбординг (этап 2)
Дата рождения + ожидаемый возраст (80) → сетка жизни («ой») → шаблон рутины → сегодняшний сосуд.
