# Vessel — дизайн (итог grill-сессии 2026-10-11)

**Суть:** планировщик, где каждый день — сосуд объёмом 24ч, а сетка дней жизни — дашборд всех сосудов.
Только план, без отслеживания реального времени. Цель — наглядно показать, как мало на самом деле свободного времени.

## Сосуд дня
- 2D: квадрат без верхней стенки, сетка 24×24 частицы. Ряд = 1 час, частица = 2.5 минуты. Шкала 0–24ч на стенке.
- Рутина — пласт на дне. Задачи ложатся сверху в порядке принятия.
- Добавление: черновик → призрачный контур → «Принять» → частицы падают с физикой (matter.js) и утрамбовываются в ровный пласт цвета категории. Высота пласта строго пропорциональна времени.
- Выполненные пласты плотные, невыполненные полупрозрачные, рутина приглушённая.
- **Новая задача не влезает** → контур краснеет, «Принять» заблокирована. Варианты: перенести на ближайший день, где влезет; сократить; убрать/перенести низкоприоритетное. «Добавить всё равно» нет.
- **Выросло существующее** (правка, рутина, повтор) → лишние частицы вываливаются через край на пол, день красный. Клик по кучке → те же варианты.

## Задача
Название, категория (готовый набор), длительность *или* интервал (через полночь — делится между днями), приоритет (3 уровня), подзадачи-чеклист, повтор (как в Google Calendar, правка «только эту / эту и следующие»), дома/вне дома (дефолт от категории).
- «Вне дома» → вопрос про дорогу (туда+обратно) → отдельный пласт «Дорога», привязанный к задаче.
- Невидимое время: сборы перед выходом и восстановление (душ после спорта) — подсказки по категории, отдельные пласты. Буфер между задачами — глобальная опция, по умолчанию выключен.

## Рутина
Шаблон пунктов (длительность + дни недели), переопределение на конкретный день. В списке — свёрнутая группа без галочек.

## Сетка жизни (этап 2)
3 зума: Жизнь (строка = год, месяцы с перегородками, «осталось N дней») → Год (календарь, клетки = мини-сосуды) → День.
Прошлое серое, сегодня зелёное, будущее неактивное. Рутина — бледное основание, запланированное — ярко.
Недельный сосуд — только просмотр, пласты сгруппированы по категориям.

## Цели (этап 3)
Выделение диапазона дней в сетке → цель полосой над днями. Опционально «N мин/день» → автоматический пласт в каждом дне диапазона. Цель копит часы: запланировано / сделано.

## Чек-ин (этап 3)
При первом открытии за день: как прошёл вчерашний день (прогресс по целям, оценка 1–5, заметка) + перенос невыполненного.

## Статистика (этап 3)
Часы по категориям, % выполненного, распределение дней по загрузке, свободные часы. Неделя/месяц.

## Онбординг (этап 2)
Дата рождения + ожидаемый возраст (80) → сетка жизни («ой») → шаблон рутины → сегодняшний сосуд.

## Техника
Vite + React + TypeScript + matter.js + zustand + IndexedDB (idb-keyval), экспорт/импорт JSON, тёмная тема. PWA → iOS позже.
