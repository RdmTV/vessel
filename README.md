# Vessel

Планировщик, где день — это сосуд на 24 часа. Дела насыпаются в него цветным песком, и сразу видно, сколько времени на самом деле свободно.

Дизайн и решения — [docs/SPEC.md](docs/SPEC.md).

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173. Данные хранятся в IndexedDB браузера; бэкап — Настройки → Экспорт.

```bash
npm test          # доменная логика
npm run build     # typecheck + production-сборка
```

## Структура

- `src/domain/` — модель и чистая логика: расчёт дня (`day.ts`), повторы (`recurrence.ts`), мутации (`mutations.ts`)
- `src/vessel/VesselEngine.ts` — сосуд: клеточная симуляция песка, струя, пролив через край, canvas-рендер
- `src/ui/` — React-компоненты
- `src/store.ts` — zustand + сохранение в IndexedDB
